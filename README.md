# Vélo Pro Solutions

Site vitrine statique (HTML/CSS), publié sur Netlify.

- `index.html` : page principale
- `merci.html` : page de confirmation du formulaire de contact (Netlify Forms)
- `img/` : photo provisoire et logos des membres du collectif

Aucune étape de build : Netlify publie le dossier racine (voir `netlify.toml`).
